FEATURES

🌾 農場

每個 Discord 帳號都有一座屬於自己的全域農場，農場屬於建立時所在的伺服器，和伺服器的朋友一起衝排行。

🌱

種田

選一種作物就種滿所有空地，種子不夠自動買。各作物生長時間不同（見操作手冊），成熟時間會在 Discord 上自動倒數。

💎

品質與突變

播種時決定品質（普通、優良、稀有、傳說）與突變（巨型、黃金、快速生長、珍稀變種），越稀有越值錢。

🐔

養殖與加工

蓋畜舍養雞、牛、羊；磨坊、烘焙坊、果醬工坊把作物加工成更值錢的麵包與果醬。

🥷

偷菜與防守

偷同一伺服器朋友成熟的作物！稻草人、警戒犬、防盜圍欄守護你的農田，巡查券查出是誰來偷。

🎰

幸運賭場

拿稀有作物比大小（價值 ×2）或猜數字（價值 ×5），贏來的獎品可以賣掉，也可以留著炫耀。

🏆

排行榜與活動

個人、伺服器內與伺服器總排行，每日／每週／每月自動發獎；每天都有不同的活動，例如免澆水、大風颳走。

🤖

奢侈品

自動播種機、自動販售機、自動澆水器與倉庫擴大卷，讓農場越來越省事。

👥

群組任務與競賽

伺服器一起完成任務、和其他伺服器比賽；農場每 7 天可以轉移到另一個伺服器一次。

🏠 建立農場與總覽
  • 在伺服器輸入 /farm →「🌱 建立農場」（或「✏️ 自訂名稱建立」）。每個 Discord 帳號只有一座農場。
  • 起始資源：500 金幣、4 格農田、倉庫 50 格。農場屬於建立時所在的伺服器。
  • 總覽會列出每格農田的作物與成熟倒數、倉庫、所屬群組、動物、加工、進行中的活動與待辦事項。
  • 總覽上的「💧 全部澆水」「🧺 全部收成」可以直接操作；「📢 分享到頻道」會把農場狀態公開貼到頻道。
  • 面板只有你看得到，15 分鐘沒操作會逾時，再輸入 /farm 即可。
🌱 農田：種植、澆水、收成
  1. 到「🌱 農田」，從選單選一種作物，會種滿所有空地；種子不夠時自動用金幣補買。
  2. 按「💧 全部澆水」，作物澆水後才開始生長（免澆水活動或自動澆水器會自動澆）。
  3. 成熟後按「🧺 全部收成」，作物進入倉庫；倉庫放不下的格子會留在農田，不會遺失。
  4. 成熟後 16 小時沒收成就會乾枯，按「🥀 清除乾枯」清掉才能再種。
  5. 「⬆️ 擴建」：500 金幣，農田 +2 格（最多 16 格）、農場等級 +1（等級越高，好品質機率越高）。需要再按一次確認。

💰 販售
  • 到「💰 販售」從選單選商品，再選賣 1、一半、全部或自訂數量。
  • 單價 = 基本售價 × 品質倍率 × 突變倍率，再加上進行中的活動加成。
  • 「全部賣出」會賣掉所有農產品與商品（需再按一次確認），但不會賣掉賭場獎品。

🎰 幸運賭場
  • 只能押稀有、傳說品質，或巨型作物、黃金作物、珍稀變種。

  • 輸了下注的作物會被沒收；贏了存成「🏆 賭場獎品」，可以在販售頁賣掉，也可以留著展示。

🎵 音樂

進入語音頻道後點歌，每個伺服器各自有播放清單、音量與循環模式。

🔴

YouTube

關鍵字搜尋、影片網址、播放清單。

🟢

Spotify

歌曲、專輯、播放清單、歌手連結，自動到 YouTube 找同一首歌來播。

「正在播放」訊息附進度條與控制按鈕：暫停、跳過、停止、循環、隨機、音量、清單。

🎧 第一次點歌
  1. 先進入任一個語音頻道（沒進語音頻道時機器人會提醒「你需要先加入一個語音頻道」）。
  2. 在文字頻道輸入 /play，在 query 欄位填歌名、YouTube／Spotify 網址或播放清單連結。
  3. 機器人會自動加入你的語音頻道並開始播放，同時貼出「正在播放」訊息與控制按鈕。
  4. 再用 /play 點其他歌，會依序加入待播清單；用 /queue 查看清單。

播放清單一次最多加入 20 首。機器人正在某個頻道播放時，其他頻道的人無法把它拉走，請到同一個頻道點歌。

❓ 常見問題
  • 機器人自己離開了？待播清單播完後閒置 5 分鐘會自動離開；語音頻道只剩機器人時，約 1 分鐘後也會離開。
  • 按按鈕沒反應，說要在同一個頻道？控制按鈕和 /skip、/pause 等指令，只有和機器人在同一個語音頻道的人能用。
  • 聲音太小／太大？預設音量 10%，用 /volume 50 或按 🔉／🔊 調整，每個伺服器會記住自己的音量。
  • Spotify 連結怎麼播？機器人會讀取歌曲名稱，到 YouTube 找同一首歌播放；歌曲、專輯、播放清單都可以；歌手連結會播他的熱門歌曲。
  • 找不到歌或連結失敗？確認網址可以公開觀看，或改用關鍵字搜尋。

我們儲存什麼
